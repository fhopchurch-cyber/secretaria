# Central de Reservas — FHOP

Painel da secretaria da **Florianópolis House of Prayer** para gerir reservas de espaço
e evitar conflitos de horário, integrando os formulários da igreja com a Google Agenda.

## Estado atual
- `painel.html` — protótipo interativo (visão de mês, filtro por espaço, motor de conflito,
  lançamento de ocorrências com tag de departamento/pastor). Roda com um retrato dos dados reais.

## Próximo passo
- Versão ao vivo como **Google Apps Script Web App**, rodando na conta `fhopchurch@fhop.com`
  (leitura das 3 planilhas + agenda; criação de eventos). Sem vínculo com contas pessoais.

## Fontes (não alteradas)
- Form 1 — Reserva de espaço (departamentos)
- Form 2 — Atendimento pastoral
- Form 3 — Reserva pastoral
- Agenda: `fhopchurch@fhop.com`
